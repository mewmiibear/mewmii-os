# Security

Always:

- Use prepared SQL statements
- Escape output
- Validate input
- Use CSRF protection
- Hash passwords
- Protect secrets

Never:

- Hardcode passwords
- Hardcode API keys
- Expose sensitive information

---

# Architecture

Reuse existing business logic.

Keep modules independent.

Prefer reusable components.

Prefer configuration over hardcoding.

Avoid duplicate code.

Maintain backward compatibility.

# Database

Never modify schema casually.

Every schema change requires:

- Migration
- schema.sql update
- Documentation
- Testing

Never destroy production data.

---

# Documentation

Every completed task updates:

- CHANGELOG.md
- IMPLEMENTATION_STATUS.md

Update any affected design documentation.
