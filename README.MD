# Mewmii OS

Mewmii OS is an ERP platform built specifically for Mewmii Bear.

It manages:

- Products
- Inventory
- Supplier Orders
- Customer Orders
- WooCommerce Sync
- Warehouse
- Finance

The long-term goal is to build an ERP comparable to Shopify Admin, while supporting workflows unique to Japanese merchandise businesses.

See /docs for architecture and development standards.
